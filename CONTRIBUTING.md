# Contributing to API Request Builder

Thank you for your interest in contributing!

## Code of Conduct

Please be respectful and constructive in issues and pull requests.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your feature or bug fix.
3. Ensure your code follows the existing style and uses TypeScript correctly.
4. Test your changes locally.
5. Submit a pull request with a clear description of the changes.

## Development Setup

```bash
npm install
npm run dev
```

Ensure `npm run build` passes without errors before submitting a PR.
